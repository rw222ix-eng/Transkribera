Lektionens upplägg:
1. Genomgång: situation A (demo)
2. Gruppuppgift: situationer B, C, D
3. Gemensam genomgång av gruppuppgiften
4. Grafisk lösning med miniräknare (demo)
5. Eget arbete: s. 125–127, 2422–2435, (2436, 2438)
Nyckelfrågan:
Titta på ekvationen – var sitter den okända?
Två vägar:
Okänd i exponenten
→ Exponentialekvation
→ Metod: logaritmera
Okänd i basen
→ Potensekvation
→ Metod: upphöj till 1/n
Funktion vs Ekvation:
Funktion:
x är fri – ger en hel kurva (alla möjliga värden)
Ekvation:
y är bestämt (= 100) – söker ett specifikt x
Grafiskt:
Rita båda → skärningspunkten ger lösningen
Situation A (demo) – Exponentialekvation
Ett prov innehåller 500 mg av ett radioaktivt ämne.
Mängden minskar med 20 % per timme. När finns 100 mg kvar?
Ställ upp ekvationen:
Minskar 20 % → förändringsfaktor a = 0,80
C = 500, a = 0,80, y = 100, x = ?
Var sitter den okända?
x sitter i exponenten → exponentialekvation → logaritmera
Lösning:
Dividera med 500:
Logaritmera:
Svar: Det finns 100 mg kvar efter ca 7,2 timmar.
Sammanfattning (diskussion):
A Radioaktivt ämne
okänd i exponenten → Exp.ekv. → logaritmera
ca 7,2 tim
B Bakterier
okänd i exponenten → Exp.ekv. → logaritmera
ca kl 02:00
C Fritt fall
okänd i basen → Potensekv. → upphöj till 1/2
ca 3,0 s
D Tjernobyl
okänd i exponenten → Exp.ekv. → logaritmera
år 2116
Mönstret:
Okänd i exponenten → exponentialekvation → logaritmera
Okänd i basen → potensekvation → upphöj till 1/n
