# Impeccable — project design config

## Design Context

### Users
Swedish gymnasium (high-school) teachers, working alone on their own Windows 11
desktop (RTX 4090 / 24 GB class). They record lessons — local audio/video files or
pasted YouTube links — and need them turned into accurate transcripts (SRT/TXT/VTT)
and organized by **date, class, and course**. They are subject-matter experts, **not**
AI/ML experts. Typical context: a busy workday, often between or right after lessons,
handling **sensitive student data** — so everything runs **locally and offline**, no
cloud, no account.

**Jobs to be done:** transcribe lessons accurately; proofread / summarize / chat with
the transcript via a local LLM (Qwen3 over an app-managed llama.cpp); extract action
items and calendar events; search what was said across the whole archive. All private,
on-device.

### Brand Personality
Calm, editorial, quietly confident. Three words: **calm · editorial · unobtrusive**.
Voice is Swedish, plain, and respectful of the teacher's time and expertise — never
chirpy, salesy, or hyped. Emotional goal: the teacher feels **in control and unhurried**,
with the software fading into the background like good paper so the *lesson content* is
the subject, not the UI.

### Aesthetic Direction
**Editorial paper + ink** (ported from the Claude Design system, 2026-07-01;
authoritative source is `app/web/static/style.css`, not the older `docs/design/*.md`).
- **Color:** warm paper canvas `#F1F2ED` + near-black ink `#161A14` — never pure
  black/white; neutrals tinted. Non-coral **sky-blue accent** `#2C6E9E`; a plum / sage /
  mustard "grade" palette for categorization. Both **light and dark** themes.
- **Type:** Inter Tight (body), **Instrument Serif italic** (display accents),
  **JetBrains Mono** (uppercase micro-labels / eyebrows only — not as generic "techy"
  shorthand).
- **Form:** sharp corners (2–5px), hairline rules, flat editorial shadows. Structure is
  print-like: mono eyebrow → serif-italic display title → lede, asymmetric grids.
- **Motion:** mask-reveal + fade-up, **expo-out easing (no bounce)**, thorough
  `prefers-reduced-motion` handling.

**References (implicit):** editorial / print-magazine layout; the Claude Design system.

**Anti-references (explicit — chosen by the owner):**
- **Generic AI / SaaS dashboard** — card grids, hero-metric tiles, gradient text,
  glassmorphism, cyan-on-dark neon. (The "AI slop" look.)
- **Dense corporate / enterprise admin UI** — cramped, cold, bureaucratic, Bootstrap-gray.
- **Anything that reads as a cloud / online service** — no account/online affordances;
  it is strictly local and offline.

### Design Principles
1. **Recede, don't perform.** The UI is quiet scaffolding; the lesson content (transcript,
   sources, answers) is the subject. Prefer whitespace and hairlines over boxes and chrome.
2. **Editorial, not dashboard.** Compose like print — mono eyebrow → serif-italic display →
   lede, asymmetric grids, hairline rules. Never card-grid/hero-metric slop; never dense
   admin tables.
3. **Local & private is the point.** Never imply the cloud. No account/online language or
   iconography; everything stays on-device.
4. **Swedish, plain, unhurried.** All user-facing text in natural Swedish; calm and
   respectful of the teacher's time — no hype, no chirp.
5. **Restrained motion; accessibility as a floor.** Purposeful mask-reveal / fade-up,
   expo-out easing, honor reduced motion. Accessibility is **best-effort (no formal WCAG
   target)** but real — keyboard-operable controls, visible focus, honest labels, live
   regions for async status. (A 2026-07 hardening pass already brought it close to AA.)
